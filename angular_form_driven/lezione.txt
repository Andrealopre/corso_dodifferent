Le proprietà dirty e pristine
Le proprietà dirty e pristine permettono di capire se il campo di input a cui sono associate è stato modificato rispetto al valore iniziale.
In tal caso dirty sarà pari a true e pristine sarà uguale a false.
Quando una delle due proprietà è pari a true, Angular applica all'elemento una delle classi CSS ng-dirty o ng-pristine per variare l'aspetto
del campo di input.

Le proprietà touched e untouched
La proprietà touched è pari a true quando si è verificato l'evento blur dell'elemento di input almeno una volta, cioè quando si
abbandona un campo per passare a quello successivo, altrimenti touched rimane uguale a false.
Quando si clicca su un campo di input si genera un focus, quando si abbandona il campo touched diventa true.
Qando la proprietà touched diventa false, untouched diventa true.
Angular permette di modificare l'aspetto visivo di un campo attraverso le due classi ng-touched e ng-untouched che vengono applicate
quando rispettive proprietà assumono un valore uguale a true.

Le proprietà valid e invalid
Le proprietà valid e invalid permettono di verificare la validità di un campo. Angular attiva la classe ng-valid, quando la proprietà
valid è pari a true e ng-invalid quando è false.
