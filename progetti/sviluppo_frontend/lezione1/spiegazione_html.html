HTML - HyperText Markup Language

Marcatori - tag

Il linguaggio html nasce per condividere documenti all'interno della stessa rete. Un ipertesto è un insieme di documenti di diverso tipo ed estensione. Non c'era css, era solo formattazione testuale. Vengono introdotte diverse estensioni per immagini, possibilità di personalizzazione, video, giochi. Modello gerarchico: tipico dei sistemi operativi con organizzazione ad albero rovesciato. Modello relazionale: le relazioni associano i modelli tra di loro. Modello reticolare: sfrutta i link per collegare i vari ipertesti, permettendo di raggiungere un documento semplicemente cliccando un link. Html nasce come linguaggio per la ricerca. Il primo documento html nasce nel 1989, il creatore è Tim Burners Lee. Hypertext Markup Language. Non è un linguaggio di programmazione ma di marcatura. L'ipertesto è un insieme di documenti che possono essere di diversa estensione. Nell'era moderna non si parla più di ipertesto ma di ipermedia poiché abbiamo l'introduzione di immagini, colori, video, audio etc... Html5: Predispone la struttura della nostra o delle nostre pagine web. Tag fondamentali ->

  • html -> Definisce il tipo di documento
  • head -> Definisce l'intestazione, ovvero la porzione di documento html dove vengono inseiriti tutti i collegamenti ipertestuali esterni statici.
  • title
  • body -> corpo della pagina web
