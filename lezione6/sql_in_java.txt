JDBC - Java DataBase Connectivity
E' una libreria java utile a stabilire una connessione tra l'app java ed un DBMS.

JDBC: 
    - Connection: è l'interfaccia responsabile della connessione
    - Statement
    - PreparedStatement (extends Statement): è una misura di sicurezza in più rispetto a Statement. E' il preparatore/compilatore di comandi SQL
    - ResultSet: è il lettore dei risultati ottenuti da una query/interrogazione a DB
Senza Connection non posso raggiungere MySql e stabilire un contatto con il database. Dopo aver stabilito la connessione bisogna scrivere i comandi. A catena, dopo il Connection, deve subentrare il
PreparedStatement che deve compilare un comando sql ed eseguire il comando stesso. Qualora le operazioni crud da fare sono inserimento, modifica e rimozione si usa il PreparedStatement.
Il ResultSet è usato se il comando sql preparato è una select. Solo di fronte ad una select deve subentrare ResultSet, in quanto rappresenta il set di risultati. Permette di leggere le righe di una
select dal PreparedStatement che permette di collegarsi al db tramite la Connection.

Connection --> PreparedStatement --> ResultSet
Connection <-- PreparedStatement <-- ResultSet

polimorfismo per interfaccia
Per ottenere una Connection:

Connection conn = DriverManager.getConnection(URLDB, USERDB, PWDDBMS);

DriverManager è una classe fornita da JDBC, così come Connection.
getConnection() deve dare un indirizzo di memoria. Deve avere 3 argomenti:
    - URLDB
    - USERDB
    - PWDDBMS

PreparedStatement ps = conn.prepareStatement("Comando sql");
//ps.execute si fa se il comando sql appartiene alla categoria DML
ps.execute();

Connessione alla mano posso chiamare il metodo che compila il comando, prepareStatement controlla che non ci siano errori nel comando.

Se il comando sql è una select non mi basta fermarmi alla connessione e al PreparedStatement

//se il comando appartiene alla categoria DQL (select) non si usa execute, si usa executeQuery();
ResultSet rs = ps.executeQuery();
